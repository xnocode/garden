# Security Policy

## Supported Versions

Only the latest code on the `main` branch receives active security updates and security enhancements.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or potential issue in this digital garden repository, please do **NOT** open a public issue.

Instead, please report it privately:
1. Contact the maintainer directly via GitHub or repository communication channels.
2. Provide a brief description of the vulnerability and steps to reproduce the issue.

### Response Commitment
We aim to review and acknowledge security reports promptly and release patches to the repository as quickly as possible. Thank you for helping keep this digital garden safe!
