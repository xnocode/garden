# Garden — Agent Instructions

## Workflow rule (from the owner)

**Always present a plan first and wait for agreement before implementing.** Every time a change is requested, describe the plan, get the owner's approval, then proceed.

## Project quick facts

- Next.js 16 App Router, React 19, Tailwind 4, shadcn/ui, TypeScript, Bun.
- Fully static site: `src/app/page.tsx` is `force-static`; navigation is client-side via `garden-client-router.tsx`. Content comes from static JSON in `src/data/` generated by `scripts/publish.ts` from the Obsidian vault in `content/`.
- Auth: NextAuth (Google OAuth + credentials). New accounts must verify their email via OTP / link (Resend) before signing in — see `src/lib/verification.ts` and `src/lib/mailer.ts`.
- Deploy: `bun run deploy` = publish → commit → push; Vercel auto-deploys.
